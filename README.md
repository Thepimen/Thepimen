### ⚡ Engineering Focus

- **Linux Internals & Kernel Security:** Building ultra-low overhead observability and intrusion detection agents using **eBPF (CO-RE)**, **C**, and **Go** (`cilium/ebpf`), syscall hooking, `procfs` enrichment, and container `cgroups` parsing.
- **Distributed Systems & Backend:** Designing fault-tolerant storage engines (*Consistent Hashing*, *Write-Ahead Logging*), decoupled microservices, message queues, and low-latency APIs.
- **Security & Automation Tooling:** Developing automated vulnerability scanners, **MITRE ATT&CK** rule engines, raw socket packet inspection tools, and native desktop applications.
